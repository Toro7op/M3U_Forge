<h1 align="center">🛠️ M3U Forge (Client-Side IPTV Tool)</h1>

<p align="center">
<strong>M3U Forge</strong> — это автономный инструмент, работающий прямо в вашем браузере. Он предназначен для глубокой обработки, чистки, валидации, сортировки и DRM-конвертации IPTV-плейлистов формата M3U/M3U8.
</p>

---

### 🌐 Запустить M3U Forge (Web Web-App)
👉 **[Открыть веб-интерфейс инструмента](https://toro7op.github.io/M3U_Forge/)**  

> 🛡️ **100% Free & Open Source:** Проект полностью бесплатный, не содержит рекламы, скрытых подписок, аналитики или трекеров. Все вычисления происходят прямо в вашем браузере (Client-Side) — ваши плейлисты, токены и ссылки провайдеров не отправляются на сторонние серверы и остаются конфиденциальными.

---

### 💎 Ключевые особенности

* **Высокопроизводительное ядро:** Тяжелые операции (сортировка, чистка атрибутов, удаление дубликатов на десятки тысяч строк) скомпилированы в бинарный код для молниеносной работы без фризов интерфейса.
* **Профессиональный редактор:** Интегрирован движок **CodeMirror** с кастомной подсветкой синтаксиса URL, тегов и DRM-свойств.
* **Нативный интерфейс:** Меню и конфигурационные панели оформлены в классическом, интуитивно понятном стиле настольных операционных систем.

---

### 🛠️ Функциональные возможности

| Раздел меню | Доступные инструменты и операции |
| :--- | :--- |
| **📁 Файл** | Открытие локальных файлов, импорт по URL, экспорт готового результата, быстрая очистка рабочей области. |
| **📝 Правка** | Умное удаление дубликатов (по URL или по имени канала), пакетное удаление всех SD каналов, фильтрация плейлиста с сохранением только лучшего качества. |
| **🔍 Поиск** | Интегрированный модуль «Найти и заменить» (`Ctrl + F`) для массовой точечной правки текстовых блоков. |
| **👁️ Вид** | Управление форматированием (монолитный режим или разделение пустой строкой между каналами), контроль переноса строк. |
| **📊 Сортировка** | Естественная сортировка, сортировка по возрастанию/убыванию (алфавит, URL, группы), а также расширенная сортировка по кастомному приоритету групп. |
| **🔒 Конвертер** | Массовая конвертация DRM KEY в форматы: `KID:KEY`, `{KID:KEY}`, `{"KID":"KEY"}`, `HEX:BASE64`, `BASE64`, SimpleTV Player. |
| **🏷️ Теги** | Мощный редактор атрибутов: удаление лишних тегов, пакетная очистка строк, инструменты разделения (`Split`) и слияния строк (`Merge`). |

---

### ⚙️ Кастомная конфигурация
Встроенный менеджер позволяет гибко настраивать внутреннее поведение утилит:
* **Приоритет групп:** Задавайте порядок следования категорий каналов с помощью интерактивного списка.
* **Черный список:** Автоматическая фильтрация и исключение нежелательного контента.
* **Защита структуры:** Опция «Не сортировать внутри группы» для сохранения оригинальной последовательности каналов провайдера.
